# 한국어 교육 앱 UI/UX 디자인 브리프

## 목적과 디자인
- 한국어 학습자를 위한 모바일 우선 앱. 가칭 토리 한국어.
- 기존 대화의 TOPIK 학습 구조를 유지하되 이번 디자인의 주 범위는 요청된 5개 학습과 상세 통계다. 홈에서 시험 훈련으로 이동할 수 있도록 연결한다.
- 귀여운 오리지널 한국 호랑이 캐릭터: 주황색 몸, 크림색 배, 둥근 줄무늬, 민트 스카프. 기존 브랜드 캐릭터를 복제하지 않는다.
- 크림 #FFF9F1, 주황 #F97330, 보라 #8B6CE8, 민트 #36A884, 본문 #282433. 흰색 카드와 둥근 모서리. 버튼 대비는 접근성 확인 후 조정한다.
- 성인 외국인 학습자가 편하게 쓸 수 있는 귀여움. 문제와 통계의 읽기 영역을 장식보다 우선한다.
- 모바일 390px 기준. 터치 영역 44px 이상. 한국어와 영어의 긴 번역문, 큰 글자, 색각 차이를 고려한다.
- 모든 데이터와 예문은 프로토타입용 예시임을 명시한다.

## 정보 구조
- 하단 탭: 오늘 / 학습 / 통계 / 내 정보.
- 오늘: 매일 퀘스트, 학습 이어하기, 연속 학습, 추천 커리큘럼, 시험 훈련 진입.
- 학습: 어휘 / 리스닝 / 문법 / 실전 회화 / 표현.
- 통계 상단 탭: 기간별 / 학습별 / 어휘력.
- 복습은 오늘과 각 학습 화면에서 바로 진입한다.

## 주요 흐름
1. 언어 선택 → 레벨 테스트 → 목표 급수·시험일·하루 시간 → 추천 커리큘럼 또는 자유 학습.
2. 오늘 → 퀘스트 → 문제 → 피드백 → 다음 문제 → 완료·출석·다음 복습.
3. 학습 → 종류 선택 → 신규/복습 → 문제 → 완료.
4. 통계 → 기간 선택 → 요약 → 상세 → 관련 복습.
5. 어휘력 → 측정 → 결과 → 날짜별 결과 → 레벨별/숙련도별 현황.

## 화면 목록과 내용
01. 오늘: 호랑이 환영 카드, 오늘 목표 진행률, 연속 학습일, 복습·새 학습·리스닝 퀘스트, 큰 이어하기 버튼.
02. 학습 허브: 5개 학습 카드, 각 카드에 오늘 학습량과 복습 대기, 시험 훈련 진입 카드.
03. 어휘: 문맥 빈칸, 예문과 선택적 번역, 정답 입력, 힌트, 이미 알아요, 정답 해설, 새 단어/복습 상태.
04. 리스닝: 재생·정지·반복·재생 속도, 소요 시간, 음성 질문과 답안. 대본은 답변 후 펼치기. 무음·이어폰 안내.
05. 문법: 한 개 학습 목표, 문장 배열 또는 빈칸, 정답과 대안 표현, 관련 개념, 재도전.
06. 실전 회화: 상황과 역할, 대화 말풍선, 녹음 시작·종료·다시 녹음, 인식 문장 수정, 내용·표현 피드백, Perfect/Excellent/Good/Nice try 등급. 마이크 권한 거부·음성 미인식 상태.
07. 표현: 상황과 의도, 자연스러운 표현 선택·완성, 존댓말·반말 표시, 다른 상황 적용, 저장·복습.
08. 학습 완료: 학습 시간·문제 수·새 항목·복습 결과·XP, 출석과 연속 학습, 홈 또는 추가 학습.
09. 기간별 통계: 주/월/년/직접 선택, 연속 학습일수, GitHub식 학습 잔디, 기간별 학습 시간 그래프, 학습 종류별 학습량 그래프.
10. 학습별 통계: 5개 종류 선택, 기간 필터, 총 학습 시간·문제 수, 기간별 그래프, 부족한 영역 복습 CTA.
11. 어휘 상세 통계: 새로 배운 단어/이미 아는 단어/복습 단어, 복습 정답률, 총 시간·문제, 기간별 추세.
12. 문법 상세 통계: 새 문장/복습 문장/복습 정답률, 총 시간·문제, 기간별 추세.
13. 표현 상세 통계: 새 표현/복습 표현/복습 정답률, 총 시간·문제, 기간별 추세.
14. 회화 상세 통계: 총 시간·문제, Perfect/Excellent/Good/Nice try 개수·비율과 기간별 분포.
15. 리스닝 상세 통계: 총 시간·문제, 기간별 학습 시간과 학습량.
16. 어휘력 요약: 알고 있는 어휘 추정 수, 어휘 이해도, 측정일, 변화 추세, 측정하기 CTA, 비교 기준 설명.
17. 날짜별 어휘력: 날짜·추정 어휘 수·이해도·변화량, 결과 상세로 이동.
18. 레벨별 어휘 현황: 레벨1~30 스크롤 목록과 필터. 각 레벨별 학습한 어휘/미학습 중 알 가능성 높음/미학습 중 모를 가능성 높음의 누적 막대와 수치.
19. 숙련도별 어휘 현황: 매우 숙달/숙달/아직 서툼/재학습 필요와 총 학습 단어. 분포와 범례, 상태별 단어 목록과 복습 버튼.
20. 단어 목록·상세: 숙련도·레벨·검색 필터, 뜻·예문·음성·최근 학습·다음 복습.
21. 내 정보: 목표와 커리큘럼 변경, 언어, 일일 목표, 알림, 접근성, 음성 데이터 설정.

## 통계 UX와 측정 정의
- 기간별 필터는 통계 화면 이동 시 유지한다. 누적 수치와 선택 기간 수치를 명확히 구분한다.
- 학습 시간은 실제 학습 활동 시간으로 집계하고 장시간 유휴는 제외한다.
- 새 항목 수와 복습 항목 수는 고유 항목 수다. 푼 문제 수는 시도 수와 구분 표시한다.
- 이미 아는 단어는 학습자의 신고와 진단 결과를 구분 저장한다.
- 복습 정답률은 정의한 복습 문제의 첫 답변 기준으로 계산하고 분모를 제공한다.
- 회화 등급은 앱 내 연습 평가임을 설명하며 공인 평가처럼 표시하지 않는다.
- 어휘 이해도는 측정한 항목에서의 이해도인지 전체 추정치인지 설명한다. 측정 방식 변경 시 비교 주의 문구를 제공한다.
- 대한민국 상위 퍼센트는 대표성 있는 비교 표본과 동일 측정법 확보 전 수치 표시 금지. 요청된 위치에는 비교 데이터 준비 중 상태와 기준 설명을 제공한다. 실제 이용자 비교를 쓰면 서비스 내 비교 집단으로 정확히 표기한다.
- 레벨별 세 분류는 중복 없이 표시한다. 미학습 어휘의 예측 상태에는 추정치 표식과 설명을 제공한다.
- 숙련도 4개 분류의 합계는 총 학습 단어 수와 일치한다.
- 잔디의 색상 강도는 선택한 지표(학습 시간 또는 문제 수)와 범례를 제공한다. 날짜 선택 시 상세 팝오버를 표시한다.
- 그래프는 색상 외에 숫자·라벨·패턴으로 의미를 전달한다.

## 필수 상태와 상호작용
- 첫 방문/데이터 없음, 로딩, 네트워크 오류, 기간에 기록 없음, 녹음 권한 거절, 녹음 처리 중, 정답/오답, 퀘스트 완료.
- 학습은 임시 저장하고 재진입 시 이어하기 제공.
- 잔디 날짜 선택, 기간 변경, 학습 종류 선택, 레벨 펼치기, 숙련도별 목록 이동이 동작하는 프로토타입.
- 캐릭터 애니메이션은 최소화 설정 지원. 오답 시 비난 없이 설명하고 재도전 유도.
- 한국어 UI 기본, 다른 언어는 설정에서 변경. 문제 원문과 설명 언어를 분리한다.

## 생성할 산출물
- 주요 화면별 모바일 고해상도 시안과 연결 가능한 프로토타입.
- 버튼·입력·카드·탭·퀴즈·그래프·잔디·호랑이 상태를 포함한 공통 컴포넌트.
- 학습 5종과 통계 3분류를 모두 포함한 화면 흐름.
- 고급 통계는 요약→상세 방식으로 분리해 한 화면 과밀을 방지한다.

## 현재 상태
Product Design 플러그인은 검색에서 발견되었으나 설치되지 않은 상태다. 연결 안내를 제공했다. 플러그인 실행이나 디자인 생성이 완료된 상태는 아니다.
