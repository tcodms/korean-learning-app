# UI 화면 현황과 시안 작업 범위

기준일: 2026-10-30. 현재 Prototype.tsx, LearningReactions.tsx, content.ts와 product-plan-v2.md를 대조했다. 실행 화면의 UX 품질 감사가 아닌 코드 기반 기능·화면 재고다. 과거 생성 이미지에만 있는 화면은 구현된 것으로 계산하지 않는다.

## 현재 구조

기본 화면은 7개다: 오늘, 학습 선택, 공통 문제, 결과, 복습, 통계, 설정. 학습 4영역은 하나의 문제 화면에서 콘텐츠와 입력 방식을 바꾸어 표시한다. 중단 확인과 체험판 안내는 별도 페이지가 아닌 하단 시트다.

| 화면 | 구현 내용 | 현재 한계 |
| --- | --- | --- |
| 오늘 | 호랑이 인사, 오늘 풀이 수/목표, 복습 개수, 학습 시작, 영역 바로가기, 연속 학습 | 추천은 고정 샘플 5문항. Continue learning도 기존 중단 위치를 복구하지 않음 |
| 학습 선택 | 어휘·듣기·문법·표현 카드, 음식·쇼핑·교통 주제 및 풀이 진도 | 카드 선택 시 바로 문제 시작. 단계/레슨 목록·소개 화면 없음 |
| 공통 문제 | 지시문, 번역/상황, 진행률, 힌트, 채점, 다음 문제, 중단 | 독립적인 네 학습 앱 화면이 아니라 공통 틀의 변형 |
| 결과 | 이번 묶음 성적, 복습 대상 수, 배운 항목, 저장, 재학습, 홈 복귀, 호랑이 축하 | 복습 전용 완료 화면은 없고 공통 결과 재사용 |
| 복습 | 오답·힌트 사용·저장 항목 목록, All/Words/Other skills 필터, 항목/묶음 학습 | 오답과 직접 저장한 항목을 목록에서 명확히 구분하지 않음. 상세 학습장 없음 |
| 통계 | 누적 제출 수, 학습 일수, 주간 막대, 정답률, 영역별 풀이 수 | 캘린더·날짜별 상세·고유 항목 수 없음. First-try accuracy는 전체 제출 정답률이라 기준 보완 필요 |
| 설정 | 하루 5/10/15문항, 느린 음성, 영어 설명 표시, 샘플 안내 | 설명 언어는 English 고정. 효과·알림·상세 출처/라이선스 설정 없음 |

## 문제 화면 변형과 상태

| 구분 | 현재 있음 | 추가 설계가 필요한 것 |
| --- | --- | --- |
| 어휘 | 문맥 빈칸 입력, 단어/뜻 선택, 보조 단어 카드 | 단어 뜻·품사·활용·예문을 모은 상세 |
| 문법 | 조사/활용 선택, 카드로 문장 배열, 카드 제거/되돌리기 | 문법 요약 및 비교 예문 상세 |
| 표현 | 상황에 맞는 표현 선택, 빈칸, 문장 배열 | 상황·말투·사용 관계를 모은 표현 상세 |
| 듣기 | TTS 재생/정지·반복·속도·대본·선택형·실패 안내 | 음성 준비 중 상태, 정리된 대본/번역 상세. 녹음 음원은 미확보 |
| 공통 상태 | 답변 전/선택 후, 비활성 확인 버튼, 키보드, 힌트, 정답·오답 해설, 북마크, 결과 | 모름/건너뛰기, 오답 직후 같은 문제 다시 입력하기, 중단 지점 복구 |
| 보조 상태 | 복습 목록 없음, 필터 결과 없음, 통계 기록 없음 문구, 음성/저장 실패 문구, 중단 확인 시트, 샘플 안내 시트, 목표 축하 | 화면 단위 로딩/불러오기 실패/재시도는 아직 없음. 서버 전제 상태는 별도 후속 범위 |

정답과 오답은 문제 화면 안의 피드백 상태이며 독립 페이지가 아니다. 힌트와 듣기 대본도 같은 화면 안에서 펼친다. 오답 재학습은 결과 또는 복습 목록에서 다시 시작하는 방식이다.

## 기획에 있으나 없는 화면·흐름

1. 첫 실행: 환영/게스트 시작, 설명 언어, 한글 읽기 여부·시작 수준, 관심 주제·목표 선택.
2. 학습 탐색: 영역별 단계/레슨 목록, 주제별 레슨 목록, 레슨 소개 및 시작 화면.
3. 학습 항목 상세: 단어·문법·표현의 뜻, 예문, 음성, 용법, 저장 상태. 복습 목록에서 상세로 들어가는 경로.
4. 학습장 확장: 저장 항목과 오답 구분, 항목 종류별 필터, 학습 상태. 복습 완료는 공통 결과를 재사용할지 결정.
5. 기록 확장: 캘린더, 날짜별 기록, 첫 시도/재도전·힌트 사용을 구분한 상세.
6. 설정 확장: 설명 언어 선택, 음성·효과, 알림, 출처·라이선스 상세.

위 목록은 미구현 현황이며 전부 오늘 반드시 추가한다는 뜻은 아니다. 가입·로그인·동기화, 결제, 관리 도구는 후속 범위다. 회화·발음 평가·TOPIK 실전은 현재 제품 범위에 넣지 않는다. 랭킹·상점·재화도 오늘 추가하지 않는다.

## 오늘 이미지 시안의 권장 구성

기존 화면을 버리고 재설계하기보다 빠진 진입·탐색·상세를 연결한다. 우선 아래 20장으로 대표 흐름을 확인한다.

| 순서 | 시안 | 기반 |
| --- | --- | --- |
| 01 | 환영·게스트 시작 | 신규 |
| 02 | 설명 언어 선택 | 신규 |
| 03 | 한글 읽기·시작 수준 선택 | 신규 |
| 04 | 관심 주제·하루 목표 선택 | 신규 |
| 05 | 오늘 홈 | 기존 |
| 06 | 학습 선택 | 기존 |
| 07 | 영역/주제 레슨 목록 | 신규 공통 틀 |
| 08 | 레슨 소개·시작 | 신규 |
| 09 | 어휘 빈칸 입력 | 기존 |
| 10 | 문법 카드 배열 | 기존 |
| 11 | 상황 표현 선택 | 기존 |
| 12 | 듣기 문제 | 기존 |
| 13 | 정답 해설 | 기존 상태 |
| 14 | 오답 해설·재도전 동작 | 기존 상태 보완 |
| 15 | 학습 결과 | 기존 |
| 16 | 복습·저장 목록 | 기존 보완 |
| 17 | 단어·표현 상세 | 신규. 문법 상세는 이 틀의 변형 |
| 18 | 기록·통계 | 기존 |
| 19 | 학습 캘린더·날짜 기록 | 신규 |
| 20 | 설정 | 기존 보완 |

별도 상태 보드: 힌트, 듣기 대본, 중단 확인, 처음의 빈 기록/복습 없음, 목표 달성. 이들은 기본 화면 수와 중복 합산하지 않는다. 로그인 UI나 API 연결을 시안 완료 조건에 넣지 않는다.

## 확정 디자인

V1 호랑이, 크림/살구 바탕, 주황 아이콘·진행, 더스티 블루 #526F91 주요 버튼. 현재 카드 형태와 눌림 효과 유지. 말풍선은 추가하지 않는다. 이미지 속 숫자는 시안용 예시임을 구분한다.
