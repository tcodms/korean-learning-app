# 호랑이 캐릭터 동작

2026-10-29. 말풍선으로 반응을 추가하던 방향을 사용자가 거부하여, 홈 말풍선을 제거하고 캐릭터의 포즈를 바꾸는 방식으로 수정했습니다.

## 구현

- `app/public/assets/learning/tiger-room-v2.png`: 호랑이를 제거한 고정 배경.
- `app/public/assets/learning/tiger-wave-strip.png`: RGBA 2172×724, 가로 4프레임. 각 셀은 543×724.
- `app/src/LearningReactions.tsx`: 캐릭터와 축하 효과.
- `app/src/prototype.css`: 포즈 전환, 정답 시 짧은 점프, 동작 줄이기 설정 대응.
- `docs/qa/character-motion/tiger-wave-preview.gif`: 생성된 포즈를 연결한 캐릭터 동작 미리보기. 브라우저 화면 녹화가 아닙니다.

홈 진입/캐릭터 클릭 시 손 흔들기와 웃는 표정, 정답 및 완료 화면에서는 같은 동작과 짧은 점프를 재생합니다. 정지 상태에서 배경과 캐릭터는 움직이지 않습니다. 초기 4포즈 애니메이션이므로 영상이나 연속적인 3D 리깅 수준의 움직임은 아닙니다.

## 이미지 제작

기존 `tiger-study.png`를 정체성과 재질 참고 이미지로 사용했습니다. 기본 내장 imagegen 도구를 사용했으며 CLI/API 대체 경로는 사용하지 않았습니다. 원본 PNG의 투명도를 보존했습니다.

프롬프트 — 캐릭터: 기존 주황 3D 아기 호랑이의 외형, 줄무늬, 크림색 주둥이·배, 검은 눈, 가 카드를 유지한다. 가로 4칸 투명 스프라이트. 각 칸의 크기·발 위치·머리 중심을 동일하게 유지한다. 1번 손 내림, 2번 손 들기, 3번 손을 바깥으로 흔들며 눈을 감고 웃기, 4번 손을 안쪽으로 흔들기. 배경·바닥·그림자·말풍선·라벨 금지.

프롬프트 — 배경: 기존 방에서 호랑이와 카드만 제거한다. 왼쪽 식물과 책, 복숭아색 아치, 햇빛과 카메라는 유지한다. 빈 자리를 방과 바닥으로 채우며 캐릭터·텍스트·UI·말풍선을 추가하지 않는다.

## 검증

브라우저에서 홈의 손 흔들기 버튼과 포즈 프레임 전환을 확인했습니다. CSS 애니메이션 tiger-wave-frames가 재생되며 background-position이 실제로 바뀌는 것을 확인했습니다. 말풍선은 DOM에서 제거되었습니다. 배경 이미지 캐시로 기존 호랑이가 겹쳐 보였던 문제는 새 배경 파일명으로 수정했습니다. TypeScript, 콘텐츠 검사 2건, 보호된 모바일 런타임 무결성 검사, 프로덕션 빌드가 통과했습니다. 목표 달성 축하 알림은 이번 세션에서 임계값 도달까지 별도로 검증하지 않았습니다.
