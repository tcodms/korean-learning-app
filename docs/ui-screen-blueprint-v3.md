# 전체 화면 텍스트 설계 v3 — 오늘의 학습 포함

기준일: 2026-10-30. 전체 화면 이미지 시안 제작용 목표 설계이며 구현 완료 목록이 아니다. 기존 구현 현황은 ui-screen-inventory.md를 참조한다. 오늘은 백엔드 연결보다 화면과 흐름을 확정한다.

## 공통 기준

- 호랑이, 크림 배경, 살구색 카드, 주황색 아이콘·진행률, 더스티 블루 #526F91 주요 버튼.
- 말풍선 추가 없음. 캐릭터 자체의 짧은 동작으로 반응한다.
- 기본 탭: 오늘 / 학습 / 복습 / 기록. 문제 풀이·초기 설정에는 하단 탭을 숨긴다.
- 아래 한국어는 설계 설명용이다. 실제 초기 체험판 해설·메뉴는 영어 우선이며 학습 문장은 한국어다.
- 숫자·카페 주제는 시안 예시다. 새 주제의 문항·음성은 별도 제작·검수가 필요하다.
- 마이크·회화·발음 채점·로그인·결제·랭킹·상점은 이번 시안 범위에서 제외한다.

## 오늘의 학습 규칙

첫 사용 시 단어·듣기·문법·표현 중 매일 공부할 영역을 사용자가 복수 선택한다. 최소 1개를 선택해야 하며 전체 선택을 강제하거나 자동으로 확정하지 않는다. 오늘 코스에는 선택한 영역만 넣는다. 선택하지 않은 영역은 자유 학습에서 계속 이용할 수 있다.

기본 10문항을 선택 영역에 배분한다. 예: 단어만 선택하면 단어 10문항, 단어+듣기면 단어 5+듣기 5. 배분 예시이며 3~4개 선택·5/15문항 목표의 세부 배분은 후속 결정한다. 각 영역 안에서 이전 복습 → 새 내용 → 새 문장/상황 적용으로 진행한다. 복습도 선택 영역 안에서 구성하고, 첫날에는 도입 문제로 대체한다. 여러 영역을 선택했을 때만 공통 상황으로 연결할 수 있으며, 다른 영역을 강제로 추가하지 않는다.

10문항 진행률은 기본 문제만 센다. 추가 오답 재도전은 별도 복습으로 표시한다. 힌트·재도전과 첫 답변 성적을 구분한다. 오늘 목표는 5/10/15문항을 선택할 수 있으며 이미지 시안은 10문항으로 통일하고 분량별 세부 편성은 후속 결정한다. 5~8분은 실측값이 아닌 설계 목표다.

하루 코스는 중간에 자유 학습을 해도 유지한다. 같은 날 다시 열면 마지막 미완료 문항부터 복귀한다. 다음 날 미완료분을 무조건 더하지 않고, 이전 코스 이어하기와 새 오늘 코스를 선택할 수 있게 한다. 일정 운영 규칙은 이후 구현에서 확정한다.

## 01 환영 / 신규
상단: 로고·임시 앱 이름.
중앙: 인사하는 호랑이, “매일 조금씩, 한국어를 내 것으로.”, “단어부터 문장과 듣기까지.”
하단: [시작하기] → 02. 계정 생성은 요구하지 않는다.

## 02 설명 언어 / 신규
상단: 뒤로, 초기 설정 진행 1/4.
본문: “어떤 언어로 설명해 드릴까요?”, 언어 선택 목록, 선택 표시. 초기 실제 지원은 영어이며 미지원 언어를 작동하는 것처럼 표시하지 않는다.
하단: [다음] → 03.

## 03 시작 수준 / 신규
상단: 뒤로, 초기 설정 진행 2/4.
본문: “어디서부터 시작할까요?”, [한글 읽기가 아직 어려워요] [한글을 읽을 수 있어요] [짧은 문장을 알아요]. 한글 입문 선택에는 입문 코스 준비 중 안내와 현재 코스 요구 수준을 표시한다. 레벨 테스트 결과나 TOPIK 급수라고 표현하지 않는다.
하단: [다음] → 04-1. 읽기 어려움 선택 시 한글 입문을 제공하는 것처럼 진행하지 않도록 안내를 먼저 보여준다.

## 04-1 매일 공부할 내용 선택 / 신규·필수
상단: 뒤로, 초기 설정 진행 3/4.
제목: “매일 어떤 공부를 하고 싶나요?”
보조: “오늘의 학습에 넣을 내용을 골라 주세요. 여러 개 선택할 수 있어요.”
2×2 선택 카드: 단어(일상 단어를 익혀요), 듣기(듣고 의미를 이해해요), 문법(문장 만드는 규칙을 배워요), 표현(상황에 맞는 말을 익혀요).
선택 상태: 체크·테두리·배경으로 함께 표시. 다시 누르면 해제. 미선택에서 시작하고 최소 1개 선택 시 [다음] 활성화.
하단: “선택한 공부로 매일 코스를 만들어 드려요. 나중에 설정에서 바꿀 수 있어요.” [다음] → 04-2.
이 화면은 관심 주제 선택과 별개다. 문법 등의 카드 내용은 설명용 예시로, 선택 즉시 문제를 시작하지 않는다.

## 04-2 관심 주제·하루 목표 / 신규
상단: 뒤로, 초기 설정 진행 4/4, [건너뛰기].
본문: 선택 영역 요약, 관심 주제 칩(일상·음식·쇼핑·교통), 목표 5/10/15문항, 선택한 목표 강조. 기본 10문항과 예상 시간 안내.
하단: [학습 준비 완료] → 05. 건너뛰기는 관심 주제·목표만 기본값으로 두며, 앞에서 선택한 영역을 네 가지 전체로 바꾸지 않는다.

## 05 오늘 홈 / 기존 보완
상단: 짧은 인사, 연속 학습 기록.
중앙: 고정된 방 배경과 움직이는 호랑이. 오늘 목표 진행, 복습 항목 수.
핵심 카드: “오늘의 학습 — 카페에서 주문하기”, “10문항 · 약 5~8분”, 선택 영역 요약(예: 단어·듣기).
버튼: 미시작 [오늘의 학습 시작] → 06 / 진행 중 [이어서 학습하기 · 6/10] → 마지막 미완료 문제 / 완료 [오늘 학습 완료]와 보조 [더 공부하기] → 13.
하단: 자유 학습 영역 바로가기, 4개 기본 탭. 복습 숫자를 누르면 18.

## 06 오늘 코스 안내 / 신규
상단: 뒤로, “오늘의 학습”.
본문: 카페에서 주문하기, “커피 한 잔을 정중하게 주문할 수 있어요.”, 문항 수·예상 시간.
단계는 선택 영역에 따라 생성한다. 예: 단어 5 → 듣기 5. 각 영역의 이전 복습과 새 내용은 그 영역 안에서 구성한다. 미시작·진행·완료를 아이콘과 글자로 구분하고 선택하지 않은 문법·표현은 표시하지 않는다.
하단: [학습 시작] → 첫 선택 영역의 문제. 필요한 이전 복습이 있으면 07과 같은 문제 상태로 시작한다.

## 07 오늘 학습 — 선택 영역의 이전 복습 / 기존 문제 틀 활용
상단: 나가기, 전체 진행 1/10, 현재 “복습”.
중앙: “지난 내용을 떠올려 볼까요?”, 이전에 틀린 단어/표현을 묻는 선택 또는 입력 문제. 예: 물 → 뜻 선택.
하단: 힌트, [확인]. 채점 후 해설과 [다음]. 별도 필수 2문항 단계가 아니며 선택 영역과 복습 이력에 따라 사용한다. 듣기만 선택했으면 듣기 복습만 제시한다.

## 08 오늘 학습 — 어휘 / 기존 문제 틀 활용
상단: 나가기, 전체 진행 n/10, 현재 “오늘의 단어”.
중앙: 뜻·문맥, 예 “커피를 마셔요.” 빈칸 입력/뜻 선택. 목표 어휘 커피·물·잔.
하단: 힌트, 입력 보조 카드, [확인] → 해설 → [다음]. 단어를 선택한 경우만 표시. 모든 영역의 마지막 문항은 코스 마지막 여부에 따라 [오늘 결과 보기]로 바뀐다.

## 09 오늘 학습 — 문장·문법 / 기존 문제 틀 활용
상단: 나가기, 전체 진행 n/10, 현재 “문장 만들기”.
중앙: “커피 한 잔을 요청해 보세요.”, 조립 영역, [커피] [한 잔] [주세요] 및 오답 카드. 다른 문항에서 조사/단위를 확인.
하단: 힌트·되돌리기, [확인] → 해설 → [다음]. 문법을 선택한 경우만 표시.

## 10 오늘 학습 — 상황 표현 / 기존 문제 틀 활용
상단: 나가기, 전체 진행 n/10, 현재 “상황에 맞게 말하기”.
중앙: “카페 직원에게 물을 부탁하려고 해요.”, 물 좀 ___, 표현 선택지.
하단: 힌트, [확인] → 정중한 표현의 짧은 설명 → [다음]. 표현을 선택한 경우만 표시. 대화하는 마이크 UI는 넣지 않는다.

## 11 오늘 학습 — 듣기·적용 / 기존 문제 틀 활용
상단: 나가기, 전체 진행 n/10, 현재 “듣고 이해하기”.
중앙: 재생 버튼, 반복·속도, “무엇을 주문했나요?” 및 선택지. 마지막 문항은 새 주문/수량 대화에서 확인.
하단: 힌트·대본 펼치기, [확인] → 대본/정답 근거 → [다음] 또는 코스 마지막이면 [오늘 결과 보기]. 듣기를 선택한 경우만 표시. 대본은 처음에 숨긴다.

## 12 오늘 학습 완료 / 기존 결과 보완
상단/중앙: 축하하는 호랑이, “오늘의 학습을 마쳤어요!”, 주제명.
기록: 기본 10문항 완료, 첫 답변 성적, 도움 사용, 다시 볼 항목. 오늘 선택 영역에서 배운 내용 요약. 미선택 영역의 항목·성적·완료 표시는 넣지 않는다.
하단: 오답이 있으면 [틀린 내용 복습하기] → 복습 학습 / [오늘 홈으로] → 05 / 낮은 강조 [더 공부하기] → 13.
기본 분량 완료와 추가 복습 완료를 구분한다. 목표 달성은 별도 첫 시도 정답률을 과장하지 않는다.

## 13 자유 학습 선택 / 기존
상단: “무엇을 공부할까요?”, 설정 진입.
중앙: 어휘·듣기·문법·표현 카드 4개. 아래 상황별 학습(음식·쇼핑·교통 등)과 진도.
이동: 영역/상황 선택 → 14. 하단 기본 탭.

## 14 영역·주제 레슨 목록 / 신규
상단: 뒤로, 선택 영역 또는 주제명.
본문: 단계 표시와 레슨 목록. 예: 기초 어휘 / 음식과 음료 / 개수와 가격. 레슨별 배울 내용·문항 수·미학습/진행/완료 상태.
이동: 레슨 선택 → 15. 영역별·주제별 화면은 같은 목록 틀을 재사용한다. 아직 없는 콘텐츠를 학습 가능한 카드로 노출하지 않는다.

## 15 레슨 소개 / 신규
상단: 뒤로, 영역·레슨 이름.
본문: 배울 단어/문형/표현, 학습 목표, 문제 수·예상 시간, 현재 진행.
하단: [학습 시작] 또는 [이어하기] → 16. 오늘 코스와 별도의 자유 학습임을 표시.

## 16 자유 학습 문제 / 기존
영역에 맞춰 08~11과 같은 문제 구성. 상단은 선택 영역에 따른 오늘 코스 흐름 대신 선택 레슨명과 레슨 진행률.
입력·선택·배열·듣기, 힌트·대본, 정오답 해설을 공통 사용.
종료 → 17. 자유 학습을 나갔다고 오늘 코스를 초기화하지 않는다.

## 17 자유 학습 결과 / 기존 보완
본문: 선택 레슨 완료, 정답/도움/복습 대상, 배운 내용과 저장.
하단: [틀린 내용 다시 보기] 또는 [다시 연습] / [레슨 목록으로] → 14 / [오늘 홈으로] → 05.
오늘 기본 코스 완료와 구분되는 제목·상태를 사용한다.

## 18 복습·내 학습장 / 기존 보완
상단: “다시 보면 내 것이 돼요”, 복습할 항목 수.
필터: [복습 필요] [내가 저장한 내용], 하위 항목 종류 구분(전체·단어·문법·표현). 오답/도움 사용 표시.
목록: 한국어 항목, 짧은 뜻, 복습 이유, 저장 상태. 항목 누름 → 19.
하단 주요 버튼: [선택 범위 복습 시작] → 공통 문제 틀. 종료 → 20. 하단 기본 탭.

## 19 학습 항목 상세 / 신규
상단: 뒤로, 저장/해제.
본문: 한국어 단어·문형·표현, 의미, 음성, 예문·번역.
유형별 정보: 단어는 품사/필요한 활용, 문법은 짧은 규칙/비교 예문, 표현은 상황/말투. 해당 정보가 없는 항목에 빈 섹션을 만들지 않는다.
하단: [이 내용 연습하기] → 관련 문항.

## 20 복습 결과 / 기존 결과 틀의 변형
본문: 복습 완료, 복습한 항목·다시 필요한 항목, 이번 첫 답변 성적.
하단: [남은 내용 다시 보기] 또는 [복습 목록으로] → 18, [오늘 홈으로] → 05.
재도전 성적을 최초 학습 성적으로 덮어쓰지 않는다.

## 21 기록·통계 / 기존 보완
상단: “조금씩 쌓이는 한국어”, 설정 진입.
본문: 학습 일수, 총 풀이 수, 주간 학습량, 영역별 풀이 수, 첫 답변 정답률과 도움 사용.
이동: [학습 캘린더 보기] → 22. 고유 항목 수는 항목 ID 기준이 마련된 뒤 표시. 초기에는 풀이 수를 단어 수라고 부르지 않는다.
하단 기본 탭.

## 22 학습 캘린더·날짜 상세 / 신규
상단: 뒤로, 월 이동.
중앙: 날짜별 학습 여부와 선택 날짜. 색상에만 의존하지 않고 표시/선택 상태를 함께 사용.
하단: 선택일의 오늘 코스 완료 여부, 공부한 레슨·영역, 풀이 수와 복습 기록. 기록 없는 날짜에는 간단한 빈 상태.

## 23 설정 / 기존 보완
상단: 뒤로, “내 학습 설정”.
항목: [매일 공부할 내용] → 04-1과 동일한 선택 화면(기존 선택 표시, [저장]), 설명 언어, 하루 목표 5/10/15, 느린 음성, 동작 줄이기/효과, [콘텐츠·출처] → 24.
언어 선택은 작은 선택창, 음성/효과는 토글로 처리하며 모든 설정마다 새 페이지를 만들지 않는다. 동작 줄이기는 기기 접근성 설정도 존중한다. 알림·계정·동기화는 실제 지원 전 노출하지 않는다.
영역·목표 변경은 다음 코스부터 적용한다고 안내한다. 이미 시작한 코스의 문항과 진도를 자동으로 삭제하거나 교체하지 않는다. 오늘 코스에 즉시 적용하는 재시작은 별도 후속 검토한다.

## 24 콘텐츠·출처 안내 / 기존 짧은 안내 확장
상단: 뒤로, “학습 콘텐츠 안내”.
본문: 체험판 자체 샘플, 검수 상태, 기기 TTS 안내, 자료별 출처·이용 조건, 기기 내 기록 저장 안내.
실제 사용하지 않은 사전/시험기관을 데이터 출처로 표시하지 않는다.

## 공통 보조 화면·상태 보드

1. 답변 전·입력/선택 후: 확인 버튼 비활성/활성, 한글 입력 키보드와 버튼 위치.
2. 정답: 정답 표시, 호랑이 짧은 반응, 완성 문장·해설·음성·저장·다음.
3. 오답: 내 답/정답/이유, [한 번 더 풀기] 또는 [다음]. 추가 시도를 첫 답변 성적과 분리.
4. 힌트: 문제를 가리지 않는 펼침 영역. 도움 사용 상태를 표시.
5. 듣기 대본: 기본 숨김, 펼치면 한국어 대본·번역. 재생 실패 시 대본으로 학습 계속.
6. 단계 전환: “다음은 문장 만들기”. 별도 필수 페이지 대신 짧은 표시로 흐름을 유지.
7. 중단 확인: [계속 학습] [저장하고 나가기]. 오늘 코스와 자유 레슨의 저장 범위를 일관되게 안내.
8. 이어하기: 중단 단계·진행률·[이어하기]. 새 코스 시작 시 기존 코스를 덮어쓰는지 명확히 안내.
9. 빈 상태: 첫 사용 기록 없음, 복습 없음, 필터 결과 없음, 날짜 기록 없음.
10. 오류/준비: 음성 준비·실패·재시도, 기기 저장 실패. 서버 오류나 오프라인 전체 지원은 아직 약속하지 않는다.
11. 목표 달성: 짧은 축하, 홈의 완료 상태. 팝업/꽃가루는 필수 버튼을 가리지 않는다.

## 시안 산출 구성

전체 흐름 지도 + 대표 장면 25개(04-1·04-2 분리) + 공통 상태 보드. 유사 화면은 같은 틀의 변형으로 묶고, 최종 이미지 개수는 가독성을 기준으로 분할한다. 네 학습 영역은 문제의 목적/입력 차이를 보여주고, 별도 브랜드 색을 배정하지 않는다. 다음 작업은 본 문서를 기준으로 기존/신규 화면을 이미지 시안으로 정리하는 것이다.
